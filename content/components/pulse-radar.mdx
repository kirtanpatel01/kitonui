## Usage

```tsx
import { PulseRadar } from "@/components/ui/pulse-radar"

export default function Demo() {
  return (
    <div className="flex justify-center p-8">
      <PulseRadar
        sweepSpeed={5}
        accentColor="emerald"
        targets={[
          { id: "fra1", x: 42, y: 32, label: "fra1-edge", region: "Frankfurt", status: "operational", latency: "14ms" },
          { id: "iad1", x: 28, y: 46, label: "iad1-edge", region: "Ashburn", status: "operational", latency: "28ms" },
        ]}
        onPing={(coords) => console.log("Probed coordinate", coords)}
      />
    </div>
  )
}
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `targets` | `RadarTarget[]` | `[]` | Edge node targets with coordinates, region, latency, and status |
| `sweepSpeed` | `number` | `5` | Rotation period in seconds per 360-degree sweep |
| `rings` | `number` | `4` | Concentric range measurement rings |
| `accentColor` | `"emerald" \| "cyan" \| "amber" \| "violet"` | `"emerald"` | System health accent color |
| `showCardinals` | `boolean` | `true` | Degree orientation indicators |
| `showGrid` | `boolean` | `true` | Crosshair grid lines |
| `interactive` | `boolean` | `true` | Enables click-to-probe coordinate deployment |
| `onPing` | `(coords: { x: number; y: number }) => void` | — | Fired when a user clicks on the radar surface |
| `onTargetClick` | `(target: RadarTarget) => void` | — | Fired when a node blip is clicked |
