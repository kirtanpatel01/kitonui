## Usage

```tsx
import { PrismCard, PrismLayer } from "@/components/ui/prism-card"

export default function Demo() {
  return (
    <div className="flex justify-center p-12">
      <PrismCard maxTilt={14} metallicSheen borderGlow>
        <PrismLayer depth={40}>
          <span className="text-xs font-mono text-zinc-400">CREDENTIAL</span>
          <h3 className="text-xl font-bold text-zinc-100">Production Access</h3>
        </PrismLayer>
        <PrismLayer depth={25}>
          <p className="text-xs text-zinc-400">
            Hardware-backed access pass with physical spring tilt response.
          </p>
        </PrismLayer>
      </PrismCard>
    </div>
  )
}
```

## Props

### PrismCard

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `maxTilt` | `number` | `14` | Maximum rotation in degrees on the X and Y axes |
| `glareOpacity` | `number` | `0.25` | Brightness of the radial cursor specular highlight |
| `metallicSheen` | `boolean` | `true` | Enables anisotropic linear specular sheen |
| `borderGlow` | `boolean` | `true` | Enables cursor-following perimeter illumination |
| `scaleOnHover` | `number` | `1.015` | Subtle scale multiplier on hover |
| `children` | `ReactNode` | Required | Content inside the card surface |

### PrismLayer

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `depth` | `number` | `30` | Distance in pixels along the Z-axis for physical parallax depth |
| `children` | `ReactNode` | Required | Content rendered on this elevation plane |
