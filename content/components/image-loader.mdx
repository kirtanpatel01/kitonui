## Usage

```tsx
import { ImageGenerationLoader } from "@/components/ui/image-loader"

export default function Demo() {
  return (
    <div className="relative overflow-hidden rounded-lg">
      <img
        src="https://images.unsplash.com/photo-1620694563886-c3a80ec55f41"
        alt="Demo"
        className="w-full object-cover"
      />
      <ImageGenerationLoader text="GENERATING" effect="scale-wave" />
    </div>
  )
}
```

## Props

| Prop | Type | Default | Description |
| --- | --- | --- | --- |
| `text` | `string` | — | Overlay label text rendered into the pixel grid in pixel typography |
| `effect` | `"scale-wave" \| "shimmer" \| "wave" \| "none"` | `"shimmer"` | Horizontal animation wave effect across the band |
| `colors` | `readonly [string, string]` | `["var(--color-blue-300)", "var(--color-blue-600)"]` | Fallback or custom gradient color palette `[from, to]` |
| `cellSize` | `number` | `5` | Size of each pixel square cell in pixels |
| `gap` | `number` | `2` | Space between pixel cells in pixels |
| `bandHeight` | `number` | `48` | Height of the scanning band in pixels |
| `duration` | `number` | `4000` | Cycle duration in milliseconds for the band traverse |
| `waveAmplitude` | `number` | `12` | Vertical bulge displacement in pixels for `"wave"` effect |
| `scaleAmplitude` | `number` | `0.75` | Scale multiplier for cells in `"scale-wave"` effect |
| `textLetterSpacing` | `number` | — | Horizontal space between pixel characters in pixels |
| `textWordSpacing` | `number` | — | Horizontal space between words in pixels |
| `overlayOpacity` | `number` | `0.3` | Opacity of the background curtain overlay |
| `overlayExitDuration`| `number` | `700` | Fade-out duration in ms when the band reaches image edges |
| `easing` | `string \| [number, number, number, number] \| function` | `"ease-in-out"` | Easing preset or cubic-bezier curve |
| `className` | `string` | — | Additional class names applied to the canvas element |

<Callout type="info" title="CORS Requirement">
  When automatic color extraction is used, the image must allow cross-origin resource sharing (`crossOrigin="anonymous"`). If the image blocks CORS, the canvas color extraction automatically falls back to the configured `colors` prop.
</Callout>
